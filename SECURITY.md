# Security Policy

## Supported Versions

Security fixes target the latest release published by this repository.

## Reporting a Vulnerability

We take security seriously. **Please do not open a public issue for security vulnerabilities.**

Preferred channel:

- [GitHub Security Advisories](../../security/advisories/new) (private disclosure, tracked with the codebase)

## What to Include

- Affected Desktop release tag or CLI version
- Reproduction steps
- Impact assessment
- Any suggested mitigation

## Our Response

We will acknowledge your report and provide an initial assessment as soon as we can.

## Public Disclosure

We will coordinate with you on disclosure timing once a fix is ready.
